# 📸 Guia de Imagens — Página de Vendas Prótese Natural

Adicione suas fotos nas pastas abaixo para personalizar a página.

---

## 📁 /instructor/
Fotos suas (instrutor do curso):
- `photo-main.jpg` → Foto principal (hero da página). Use uma foto profissional, bem iluminada, olhando para a câmera.
- `photo-about.jpg` → Foto para a seção "Sobre o Método". Pode ser trabalhando, no estúdio, etc.
- `photo-signature.png` → Sua assinatura digitalizada (opcional, fundo transparente).

**Tamanho ideal:** 800x800px ou maior (a página ajusta automaticamente).

---

## 📁 /results/
Fotos de antes e depois / resultados de clientes:
- `before-after-1.jpg`
- `before-after-2.jpg`
- `before-after-3.jpg`
- `before-after-4.jpg`
- `result-1.jpg` a `result-6.jpg` → Fotos de resultados individuais.

**Tamanho ideal:** 600x800px (retrato) ou 800x600px (paisagem).

---

## 📁 /testimonials/
Fotos dos alunos que deram depoimento:
- `testimonial-1.jpg`
- `testimonial-2.jpg`
- `testimonial-3.jpg`
- `testimonial-4.jpg`

**Tamanho ideal:** 200x200px (quadrada, para avatar) ou maior.

---

## 📁 /logos/
Logotipos e marcas:
- `logo.png` → Logo do seu negócio/curso (fundo transparente).
- `logo-white.png` → Versão branca do logo (para áreas escuras).
- `payment-methods.png` → Selos de pagamento (opcional).

---

## 📁 /icons/
Ícones personalizados (opcional, a página já usa ícones embutidos):
- `icon-certificate.png`
- `icon-support.png`
- Etc.

---

## 📁 /background/
Imagens de fundo (opcional):
- `hero-bg.jpg` → Fundo do topo da página (1920x1080px mínimo).
- `section-bg.jpg` → Fundo para seções intermediárias.
- `texture.png` → Textura sutil (opcional).

---

## ⚠️ Dicas Importantes
1. Use imagens **de alta qualidade** — fotos borradas prejudicam a conversão.
2. Prefira formato **JPG** para fotos e **PNG** para logos/ícones com transparência.
3. Comprima as imagens para web (use https://tinypng.com).
4. Fotos com boa iluminação natural passam mais credibilidade.
